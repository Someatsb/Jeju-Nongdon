# 인터넷 체험판 (Render 웹 서비스)

심사위원이 설치 없이 눌러 볼 수 있게 재생 모드 체험판을 인터넷에 띄운다. PC 에서 쓰는 설치본은 달라지지 않는다.

## 되는 것 / 안 되는 것
- 되는 것: 첫 화면, 시연 농가 다섯(노지감귤, 당근, 마늘·월동무, 양배추, 브로콜리) 바로 해 보기(AI 설명 문장까지, 저장해 둔 답변), 직접 입력(규칙 계산 결과), 종이 화면·인쇄 미리보기, 지원 전체 보기, 마을 안내용 종이, 읽기만 하는 직원 화면(자료 상태·공고 초안 보기).
- 안 되는 것(누르면 "체험판에서는 쓸 수 없어요. 설치본에서 쓸 수 있어요."): 새 공고 찾아보기 등 직원 쪽 쓰기 요청 전부. 표 고치기·공고 올리기·키 넣기는 원래 화면이 아니라 설치본 명령(bat)이라 인터넷에는 없다.
- 문자 알림: 화면은 그대로 보이지만 신청하면 "체험판이라 저장하지 않았어요"라고만 알리고 번호를 읽지도 저장하지도 기록하지도 않는다.
- 실제 AI 는 부르지 않고 `.env`·열쇠 저장소를 읽지 않는다. 열쇠가 없어도 뜬다.

## 띄우는 순서
1. `jeju-chaenggim/` 폴더를 뿌리로 하는 공개 저장소를 만든다(`render.yaml`, `requirements.txt`, `app/`, `data/` 가 뿌리에 있어야 한다).
2. Render 에서 New > Blueprint 로 그 저장소를 고른다. 설정은 `render.yaml` 에 있다(등급은 잠들지 않는 `starter`. 무료로 띄우려면 `plan: free` 로 바꾼다).
3. 올라오면 주소 `/health` 가 `{"ok":true,...}` 인지 본다.
- 이 PC 에서 시험: `JC_PUBLIC_DEMO=1 PORT=8981 python -X utf8 -m app.serve` (Windows PowerShell 은 `$env:JC_PUBLIC_DEMO=1; $env:PORT=8981`).

## 알아 둘 것
- 무료 등급(`plan: free`)은 15분 동안 아무도 안 쓰면 잠들고, 잠든 뒤 처음 열면 다시 깨는 데 1분쯤 걸린다. 그래서 심사 기간에는 잠들지 않는 `starter` 등급으로 둔다.
- 재시작하면 메모리의 상담이 사라진다(파일은 쓰지 않는다).
- 동시에 들고 있는 상담은 100개까지, 넘으면 가장 오래 안 쓴 것부터 지운다. 이 PC 실측 메모리는 약 175MB 에서 멈췄다(한도 512MB).
- 다른 사이트에서 온 POST 는 막고, 같은 주소(프록시 뒤면 X-Forwarded-Host)에서 온 것은 통과시킨다.
- 이 PC(Windows)에서만 시험했다. 리눅스 설치는 `pip download` 로 리눅스용 휠이 모두 있는 것만 확인했다.
