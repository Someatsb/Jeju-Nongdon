# 앞면 넘침 추정기 실측 (2026-11-13)

도구: `scripts/front_measure.py <PORT>`. 재생 서버(`python -X utf8 -m app.launch --replay --asof 2026-11-13 --nobrowser`)에서 시연 농가 P1~P5를 제출하고 `/counsel/preview?view=screen`의 앞면을 잰다.

측정 조건: Playwright(Chromium), 창 1600×3400, 96dpi. 16pt 한 줄(줄 간격 1.3) ≈ 7.3mm ≈ 27.6px. "남는 px"는 본문(.front .body) 아래쪽과 마지막 요소 끝의 차이, "넘침 px"는 본문의 scrollHeight − clientHeight. 설명 문장(.narr)은 미리보기에 실제로 찍힌 수. 실호출 없음.

## 보정 전 문제 (한도 41.5, 달력 이름표 있음)

P4가 추정 40.4인데 실제로는 70px 넘쳐 고정 줄(영농도우미·재해) 둘이 잘렸다(바닥글은 그대로라 겉보기에 멀쩡함). 추정기는 달력 칸·가실 곳 상자의 꺾임과 설명 문장 줄 간격을 약 2줄 적게 셌다.

## 보정 내용 (`app/ui/render.py`, 커밋 978c8b3)

- 달력 옆 이름표를 없애 세 칸을 넓힘, 달력·상자 꺾임(`REAL_WIDTH` 0.82)과 설명 문장 줄 간격(`NARR_EXTRA` 0.32)을 추정에 반영.
- 상한: 담을 수 있는 줄 수(추정 + 남는 px/27.6)의 최소가 41.5(P4)라 여유 0.5줄(14px)을 두어 41.0.
