# 운영 안내

대상: 센터 담당자(교체되어도 이 문서만 보고 이어받을 수 있게). 명령은 설치 폴더(`jeju-chaenggim`)에서 실행합니다.

## 1. 연간 달력

2026년 실제 일정을 근거로 한 것이며 2027년 일정은 공고 전이라 **확인 전**입니다. 표(`supports.csv`)의 "작년 기준" 행은 이 달력의 달에 공고를 확인해 고칩니다.

| 달 | 열리는 제도(2026 실제) | 담당자가 할 일 |
|---|---|---|
| 12월 말~1월 초 | 통합공고(2026.1.2~1.16): 칼슘유황·소형농기계·관수시설·방풍수·봉지피복·생분해 | 다음 해 공고 반영, 표 갱신(`tables.bat`) |
| 1월 말 | 소규모 농가 경영안정(2.3~2.23) | 공고 확인 |
| 2월 말 | 농민수당·여성농업인 행복이용권(3.9~3.31), 직불금(3.1~5.31) | 공고 확인, 표 갱신 |
| 4월 초 | 감귤·만감류 보험(4.27~5.29). 토양생태환경보전(5.18~5.29) | 일정 확인, 문자 안내 대상 확인 |
| 7월 | 당근 재해보험(7.1~9.30) | 일정 확인 |
| 8월 초 | 월동무 보험(8~10월), 양배추·브로콜리 보험(8~9월). 문자 안내 주 시기 | 일정 확인, `reminders due --month` |
| 10월 | 마늘 재해(10.12~11.13)·양파(10.19~11.27) 보험, 수입안정(10.1~11.30) | 감귤 시즌값 입력, 일정 확인 |
| 11월 | 월동채소 시즌 시작. 도 면적 발표 | 시즌값(`params_by_season.csv`: 기준가·물류비 단가·면적) 입력, **도매가 갱신(`data.bat`)**. 상담 성수기 |
| 12월 | - | 연말 전에 **2027 행 준비**(5절 한계 2번), 도매가 갱신, 연간 점검 |

데이터 갱신 시점: 도매가(1361·수급센터)는 상담 성수기(11~3월)에 월 1~2회와 시즌 시작 전. 지원제도 표는 위 공고 시기. 시즌값은 시즌 시작 전 한 번.

낡으면 덜 말합니다: 시세가 15일 이상 오래되면 진행 중 반월은 판정하지 않고 "자료 오래됨"으로 표시합니다. `valid_to`가 지난 행은 인쇄하지 않습니다.

## 2. 인수인계 체크리스트

- [ ] **키**: `keys.bat show`로 llm·hub 저장 여부(끝 4자리만 보임). 키는 Windows 자격 증명 관리자에 PC·계정별로 묶여 있어 **새 PC·새 계정에서는 다시 입력**(`keys.bat set llm`). 결제 명의와 재발급 절차는 별도 기록(비밀번호는 문서에 쓰지 않음).
- [ ] **`.env` 위치**: 읽는 순서는 자격 증명 저장소 → 환경변수 → `JC_ENV_FILE`이 가리키는 파일 → `jeju-chaenggim\.env`(설치 폴더; `build_zip`이 `.env*` 전부 제외) → `%USERPROFILE%\.jeju-chaenggim\.env`. 변수: `ANTHROPIC_API_KEY`, `JC_LLM_PROVIDER=anthropic`, `JC_LLM_MODEL=claude-opus-5-5`. 평문 파일이므로 PC 접근 권한을 확인.
- [ ] **백업**: 표 교체(`tables.bat apply`) 때마다 `data\backup`에 자동 백업. `tables.bat rollback`으로 가장 최근 백업 복원. 설치 폴더 전체는 압축 사본을 따로 보관.
- [ ] **문자 번호 정리**: `reminders purge`(13개월 지난 것 삭제), 발송 뒤 `reminders sent --month`, 내보낸 CSV 삭제. 번호는 DPAPI로 이 PC·이 Windows 계정에 묶여 새 계정에서는 읽히지 않음(`읽을 수 없는 알림 파일`로 나오면 `reminders forget <상담번호>`).
- [ ] **기록(logs)**: `logs\sessions\YYYY-MM.jsonl`(상담번호·구간·코드만, 이름·번호 없음), `logs\review\`(AI 문장 검수), `logs\table_changes.jsonl`(표 변경 이력). 개인정보 없음을 가끔 확인. 보존 기한을 정해 오래된 파일 정리.
- [ ] **설치 점검**: `check_install.bat`(12가지)가 [오류] 없이 통과하는지. [주의]는 프린터·Edge·키처럼 없어도 화면이 도는 것.
- [ ] **계정 인수표**: 허브 계정 소유자, 허브 공지 확인 담당(약관상 공지 확인 의무), 지원제도 문의처 목록.
- [ ] **시험**: `run_tests.bat` 결과가 `tests\REPORT.txt`에 남는지.
- [ ] 새 담당자 첫 주: `check_install.bat` → 키 재입력 → `tables.bat check` → 문자 처리 예정일 확인 → 상담 1건 같이 해 보기.

## 3. 문자 안내 처리 (담당자)

명령은 `cli.bat reminders …`로 실행합니다. 시스템 Python만 있을 때는 `python -X utf8 -m app.cli reminders …`로 같은 명령입니다.

1. 매달 발송 대상: `cli.bat reminders due --month 2027-04` (화면에는 번호 끝 4자리만).
2. 센터 문자 발송용 파일: `--export 파일.csv`를 더함. 설치 폴더 `data` 안과 이미 있는 파일 이름은 거부됩니다.
3. **발송 후 삭제**: 보낸 뒤 `cli.bat reminders sent --month 2027-04`(모두 보내면 저장 파일이 지워짐), 내보낸 CSV는 바로 삭제.
4. 요청이 있으면 `reminders forget <상담번호>`, 보관 13개월이 지난 것은 `reminders purge`.
5. `--asof` 시연 중에는 `sent`·`purge`가 지우지 않고 내보내기는 거부됩니다. `forget`은 시연 중에도 실제로 지웁니다(코드에 시연 가드 없음).

## 4. 직원 교육 30분 요점
숫자는 표가 만든다 / 판정하지 않는다("조건에 맞을 수 있습니다") / 종이에 있는 숫자만 읽는다 / 인쇄 보류는 담당자에게 / 번호는 동의 받은 것만. 자세히는 `docs/2_user_manual.md`.

## 5. 알려진 한계

1. **localhost 연결 흔들림**: 보안 프로그램이 있는 PC에서 로컬 연결이 가끔 실패합니다(`WinError 10014`). 실행기는 몇 번 다시 시도하고 다음 포트로 넘어갑니다. 15초 안에 못 켜지면 한국어 안내가 뜹니다. 잠시 뒤 `run.bat`을 다시 실행하거나 보안 프로그램 예외를 확인하세요. 시험(`run_tests.bat`)의 `tests/ui`에도 ERROR가 가끔 섞이지만 코드 실패가 아닙니다.
2. **12월 말 이후 첫 화면의 "곧 마감되는 지원"**: 이 목록(30일 안에 열리거나 닫히는 지원 최대 3개)은 `valid_to`가 지난 제도를 건너뜁니다. 지금 표는 대부분 `valid_to`가 2026-12-31이라, 2027-01-01 이후에는 표의 지원이 목록에서 빠져 비고(AI가 읽은 공고가 없으면 "지원 전체 보기" 단추만 남습니다). 제도가 없는 것이 아니라 **표 갱신이 필요하다는 신호**입니다.
3. **표를 바꾸면 녹화를 다시 만들어야** 합니다. 키 없는 시연(`run_replay.bat`)이 재생하는 녹화 응답은 그때의 표·숫자 지문에 맞춰져 있습니다. 표·시즌값을 바꾼 뒤에는 녹화를 다시 만들고 `samples/`도 `scripts\make_samples.py`로 다시 만듭니다.
4. 시세는 전국 도매 평균(1361)이라 제주 산지가와 다를 수 있습니다. 당근은 "근처 — 농협 확인"이 많이 나옵니다(`docs/3_data_spec.md`).
5. 공고 전이라 상당수 행이 "작년 기준"입니다. 감귤 가격안정·행복택시 등 5행은 hold(숫자 인쇄 안 함).
6. 프린터 출력은 현장 PC에서 확인이 필요합니다(PDF 저장까지만 확인됨).
7. 센터의 문자 발송 수단은 미확인이라 앱은 "발송 목록" 출력까지만 합니다.
