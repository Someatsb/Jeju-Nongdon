# 제주 농돈 (jeju-chaenggim)

농가가 받을 돈, 한 장으로. 어르신이 큰 단추를 눌러 몇 가지 질문에 답하면(가족·이장님이 대신 답해도 됩니다), 받을 수 있는 돈·지금 할 일·앞으로 신청할 것·보험·가실 곳을 표 하나로 정리해 종이로 인쇄합니다(종이는 어르신용 한 장 한 면이고, 직원이 볼 내용은 화면의 "직원용 · 자세한 내용 보기"에 있습니다). 이름과 주소는 묻지 않습니다.
모든 숫자는 코드가 표(CSV)와 도매가 저장본에서 계산합니다. AI(선택)는 숫자 없는 짧은 설명만 쓰고, 규칙 검사와 심사를 통과한 문장만 종이에 실립니다.
키가 없어도 같은 종이가 나옵니다(설명은 기본 문장). 센터 PC 한 대에서 로컬로만 돌고, 어르신 이름·번호는 저장하지 않습니다.

## 설치 (5단계)

1. 압축을 풉니다. 경로에 한글·공백이 있어도 됩니다. 인터넷은 필요 없습니다(내장 파이썬 `runtime\python`이 들어 있을 때).
2. `check_install.bat`을 더블클릭합니다. 12가지를 [통과]/[주의]/[오류]로 알려 줍니다. [오류]가 없으면 됩니다.
3. (선택) AI 설명을 쓰려면 `keys.bat set llm`을 실행해 키를 붙여 넣습니다. 건너뛰어도 됩니다.
4. `run.bat`을 더블클릭합니다. 검은 창이 뜨며, 닫으면 꺼집니다(최소화해 두세요).
5. Edge가 자동으로 열립니다. 안 열리면 검은 창에 적힌 주소(`http://127.0.0.1:8765` 등)를 입력하세요.

## 실행

| 목적 | 명령 | 비고 |
|---|---|---|
| 평소 | `run.bat` | 오늘 날짜 기준 |
| 고정 기준일 | `run.bat --asof 2026-11-13` | 그 날짜 기준으로 계산하고 종이 머리에 기준일 날짜가 찍힘. 네트워크 갱신은 꺼짐 |
| 키 없는 체험 | `run_replay.bat`(내장 파이썬 `runtime\python`을 쓰고, 없으면 시스템 Python) | 손으로 쓴 응답을 사용. 어르신 화면에는 체험 표시가 없고, 직원 메뉴(`/staff`) 맨 아래에 "체험 모드 · 미리 저장해 둔 AI 답변을 써요"로 시작하는 줄이 보임. 체험 농가 P1~P5를 입력 |
| 포트 지정 | `run.bat --port 8770` | 기본 8765, 쓰이고 있으면 8775까지 빈 포트를 찾음 |

| 결과 | `/counsel/preview` | 한 화면: 맨 위에 감귤 주황 바탕의 결론 띠(결론 한 줄 · AI 쉬운 말 한 문장 · 답 요약과 "답 고치기" · "소리로 듣기"), 그 아래 **표 하나**입니다. 칸은 대분류(「지금 하실 일 · ○곳」·「앞으로 신청할 것 · ○가지」) | 가실 곳과 전화(앞으로 구역은 때) | 지원 이름 | 설명(금액 · 언제 · 마감 알약 · 덧말)입니다. 한 곳에 지원이 여러 개면 곳 칸은 한 번만 나오고, 마감이 있으면 "오늘까지"·"○일 남음" 알약, 먼저 해야 받을 수 있는 것은 "이것을 해야 ○○을 받을 수 있어요"가 붙습니다. ## 재현 명령

- 전체 시험: `run_tests.bat` → 끝나면 `tests\REPORT.txt`에 시험 결과와 골든 결과가 적힙니다. 골든 12건: 12건 통과(`tests/REPORT.txt` 2026-11-19 08:12판 "3636 passed, 45 skipped, 1 xfailed", "golden 12 passed"). 이 파일은 경고도 실패로 세는 `-W error`로 돌린 결과입니다.
- 샘플 다시 만들기: `python -X utf8 scripts\make_samples.py --asof 2026-11-13` (PDF는 Edge 필요, `--no-pdf`로 HTML만).
- 비밀 검사: `python -I scripts\check_secrets.py` → `OK 0 hits`.
- 알려진 흔들림: 이 PC에서는 localhost 연결이 가끔 실패해 `tests/ui`에 ERROR가 섞일 수 있습니다. 코드 실패가 아니며 다시 돌리면 됩니다.
